# Project Guidance

- Do not assume an implementation language or deployment target until that
  choice is explicitly made.
- Never commit credentials, private keys, access tokens, or private
  infrastructure details.
- Use clearly fictional values in examples and tests.
- Do not deploy services, publish artifacts, or push changes without explicit
  approval.
- Run `just check` before committing.
- Write code, comments, commits, and repository documentation in English.
